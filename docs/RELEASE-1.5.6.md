# Better UI Imropvement 1.5.6

修复 Windows 版 Codex 26.1120.5083.0 中置顶会话丢失项目配色的问题。置顶列表按 Codex 的会话归属读取项目颜色，包括关联到云项目的本地会话。明确无项目的会话保留默认背景。

在该版本的实际侧栏中核对了 6 条置顶会话：2 条本地项目会话和 2 条关联云项目的会话与所属项目同色，2 条无项目会话保留默认背景。通过 Codex Script Loader 检查插件更新，或安装 `better-ui-imropvement-1.5.6.zip` 并使用同名 `.sha256` 校验。

## English

Pinned chats once again use their project’s sidebar color on Codex Desktop for Windows 26.1120.5083.0. Better UI reads Codex’s project assignments, including links between local and cloud projects. Chats explicitly outside a project retain the default background.

The live sidebar check covered two local project chats, two chats linked to cloud projects and two projectless chats. Update through Codex Script Loader or install `better-ui-imropvement-1.5.6.zip` and verify its accompanying SHA-256 file.
