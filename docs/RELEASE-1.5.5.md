# Better UI Imropvement 1.5.5

侧栏项目现在可以在保持打开的同时，将展开的会话列表恢复为默认的 5 条。

## 新增

- 点击“展开显示”后，旁边会出现“收起”。即使已经显示全部会话，“收起”仍保留在列表末尾。点击只会收起当前项目的会话列表。
- “收起”沿用原生分页按钮的字体、间距和交互样式。此功能默认开启，可以在 **界面增强 → 侧栏 → 项目会话收起按钮** 中关闭。

## 升级

通过 Codex Script Loader 更新，或安装独立包 `better-ui-imropvement-1.5.5.zip`。下载页提供对应的 SHA-256 校验文件。候选已在 Windows Codex 26.1111.9664.0 上完成验收。

---

Expanded sidebar projects now have a **Show less** button that restores the default five chats while keeping the project open.

## Added

- After you select **Show more**, **Show less** appears beside it. Once all chats are visible, **Show less** stays at the bottom of the list. It affects only the selected project.
- **Show less** uses the native pagination button’s typography, spacing, and interaction styles. The feature is on by default and can be turned off in the sidebar section of **Interface enhancements**.

## Upgrade

Update through Codex Script Loader or install `better-ui-imropvement-1.5.5.zip`. A SHA-256 checksum is available alongside the ZIP. The candidate was verified on Windows Codex 26.1111.9664.0.
