# Better UI Imropvement 1.5.7

修复 Windows 版 Codex 26.1120.5083.0 中配色设置显示“Codex 选项组件不可用”的问题。配色预设、模式和项目颜色现在从 Codex 已加载的 Rspack 模块取得原生菜单。如果菜单加载或渲染失败，页面会显示原有的下拉框，仍可修改选项。候选已热加载，并在实际配色设置页确认可用。

通过 Codex Script Loader 检查插件更新，或下载 `better-ui-imropvement-1.5.7.zip` 并核对同名 SHA-256 文件。

## English

Restores the preset, mode and project color menus on Codex Desktop for Windows 26.1120.5083.0. Better UI locates the native menu in Codex's loaded Rspack modules. If loading or rendering the menu fails, the original select control stays usable. The fix was confirmed on the live color settings page.

Update through Codex Script Loader, or install `better-ui-imropvement-1.5.7.zip` after checking its SHA-256 file.
